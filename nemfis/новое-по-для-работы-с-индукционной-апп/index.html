Новое ПО для работы с индукционной аппаратурой

16.05.2015

Предлагаем ознакомиться с новым программным обеспечением для работы с индукционной аппаратурой (АЭМП-14, ЭМС) с помощью устройств на Android OS.

Скачать последние версии программ, добавить информацию об ошибках, отслеживать их устранения, посмотреть отчёты о решенных проблем в ПО и оставить свои комментарии вы можете перейдя по ссылкам:

– iiSystem – программа для сборки и компоновки данных к отчету

– QZond – программа для управления работой и визуализации данных индукционной аппаратуры.
