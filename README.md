# АСУ-ЭКСПЕРТ — редизайн сайта

Новый статический сайт для ООО «АСУ-ЭКСПЕРТ» (asu-expert.ru): весь контент старого сайта перенесён в современный дизайн.

- **`site/`** — готовый сайт. Его можно залить на любой хостинг как есть (31 страница, без сборки).
- **`src/`** — исходники и генератор.

## Что внутри

| Страница | Файл |
|---|---|
| Главная: экран разделён пополам — слева текст, справа неподвижная картинка, которая меняется по разделам; подбор прибора по методам, кадры из скважин, заказчики, отгрузки | `index.html` |
| Каталог и 4 раздела | `catalog.html`, `registrators.html`, `electric.html`, `perforation.html`, `video.html` |
| 20 страниц приборов с техописанием | `kp-51e.html`, `geofit-1003.html`, … |
| О компании + реквизиты, контакты с картой и формой запроса, заказчики, 424 новости с поиском, сертификаты | `company.html`, `contacts.html`, `clients.html`, `news.html`, `certificates.html` |

Светлая тема в фирменных цветах (синий и красный), шрифт IBM Plex. Подбор прибора: отмечаете методы (КС и ПС, ГК, видеокаротаж…) и остаются подходящие приборы.

Без внешних JS-библиотек. Учтён `prefers-reduced-motion`.

## Фотографии

Снимки приборов, кадры видеокаротажа, диаграммы и документы — со старого сайта asu-expert.ru. Фото буровых, керна, Томска и видео из скважины взяты с Wikimedia Commons под свободными лицензиями (CC BY, CC BY-SA, public domain). Авторы и лицензии перечислены в `src/data/photo-credits.json` и в подвале каждой страницы. Их стоит заменить собственными фотографиями предприятия, когда они появятся.

## Как пересобрать

```bash
python3 src/crawl.py      # (по желанию) заново скачать страницы с asu-expert.ru -> src/data/pages.json
python3 src/extract.py    # очистить HTML старого сайта (Word-разметку) -> src/data/content.json
python3 src/build.py      # собрать сайт в site/
```

Нужен Python 3 с `beautifulsoup4` и `lxml` (только для `extract.py`; `build.py` работает на стандартной библиотеке).

Тексты карточек, контакты и список заказчиков редактируются в начале `src/build.py`, стили — в `src/static/css/main.css`.

Посмотреть локально:

```bash
cd site && python3 -m http.server 8000
```
