Техническое описание

Комплексный скважинный прибор «КП–242ЭГ».

Назначение

Комплексный скважинный прибор «КП–242ЭГ» предназначен для измерения уровня естественного гамма-излучения пород (ГК) и токового каротажа в скважинах с максимальной температурой +80°С.

Прибор рассчитан на работу совместно с цифровыми регистрирующими комплексами (станциями, лабораториями) через геофизический трехжильный бронированный кабель.

Технические характеристики

1. Пределы и погрешность регистрации:

  • для зонда ГК1 .................................................................... 0…500 мкр/час, ±20 %;
  • для зонда ГК2 ............................................................... 0…14.000 мкр/час, ±30 %;
  • для зонда токового каротажа (ТК):
  • ток излучения - 0…80 мА
  • разрешающая способность по току - 40 мкА.

2. Условия работы прибора:

  • максимальная температура окружающей среды .................................................. 80 °С.
  • наибольшее гидростатическое давление .......................................................... 10 МПа.
  • 3. Напряжение постоянного тока питания прибора, В ............................................ 140…200.
  • 4. Прибор оснащен цифровой телеизмерительной системой «Манчестер-2».
  • 5. Проведение измерений осуществляется со скоростью до 400 м/ч при шаге квантования по глубине, равном 10 см.

6. Габаритные размеры прибора, мм:

  • диаметр по охранному кожуху ................................................................................. 36;
  • длина с транспортной заглушкой ......................................................................... 1900.

7. Масса прибора, кг, не более .......................................................................................... 12.

8. Прибор «КП-242ЭГ» рассчитан на эксплуатацию в условиях, соответствующих:

  • по механическим воздействиям ............................... группе МС2-3 по ГОСТ 26116-84;
  • по климатическим параметрам ................................. группе КС4-2 по ГОСТ 26116-84.

Прибор имеет Декларацию о соответствии ЕВРОАЗИАТСКИЙ ЭКОНОМИЧЕСКИЙ СОЮЗ ЕАЭС N RU Д-RU/АБ88.В.01571/19
