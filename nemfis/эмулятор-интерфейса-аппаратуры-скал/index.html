Эмулятор интерфейса аппаратуры Скала-64

11.03.2014

I-Emu это рабочий инструмент для тех, кто использует аппаратуру “Скала-64”. С его помощью можно создавать шаблоны измерений и оценивать длительность работы при их использовании без самой аппаратуры.
Если требуется удаленно от прибора создать нужный шаблон, это можно сделать на обычном компьютере, с помощью I-Emu, а затем отправить сформированный файл с шаблонами оператору. Также эта программа полезна тем, что с её помощью можно посмотреть, как для оператора в поле выглядели, какие-либо данные на экране прибора. Данную программу можно скачать в разделе “Программное обеспечение”.
