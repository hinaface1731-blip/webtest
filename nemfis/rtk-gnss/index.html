Система точного позиционирования RTK GNSS

01.08.2016

Представляем новую систему позиционирования для точной локализации индукционной аппаратуры на открытом пространстве.

Комплект поставки состоит из двух блоков один из которых является “базой”, формирующий поправки для второго блока носимого вместе с измерительным оборудованием. В основе используются приемники Ublox NEO-8T, обеспечивающие работу в комбинированном режиме GLONASS/GPS с частотой – 5Гц.

В режиме RTK база передает на приемник поправки по радиоканалу 900МГц, таким образом автономная работа модулей с предоставлением точных координат обеспечивается на удалении до 1,5 км устройств друг от друга.
Для конечного пользователя имеется возможность получения координат в форматах LLH, XYZ, NMEA или ENU. Имеется возможность записи лога в формате RINEX.

Пользователь может использовать любой софт, где есть возможность подключения GNSS приемника по протоколам TCP IP, UART или Bluetooth, а также специализированное ПО, где есть возможность импорта данных в формате RINEX.

Первичная настройка осуществляется с помощью сервисного ПО, работающего практически на любой платформе (Android, Windows Mobile, Mac OS, Linux, Windows PC и пр.).

Питание модулей осуществляется от встроенного 5В аккумулятора, при полной зарядке обеспечивается работа в течение 4-6 часов (в зависимости от выбранного протокола обмена с конечным устройством пользователя куда передаются координаты).
