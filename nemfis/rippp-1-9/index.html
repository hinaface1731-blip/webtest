RIPPP 1.9

06.06.2014

Уважаемые пользователи ПО “RiPPP”!

Рады сообщить о выходе новой версии. Если Вы уже используете ПО “RiPPP”, выполните проверку обновления (“Помощь – Проверить обновления”).
Новая версия также доступна на нашем сайте в разделе “Поддержка” -> “Программное обеспечение“.

Пожалуйста, присылайте отчёты об ошибках и предложения по адресу m64Developers@gmail.com и подписывайтесь на рассылку новостей об обновлениях ПО и инструкций.

История изменений:

[1.9]
Исправлено: Экспорт проекта в файл *.data (ERTLab)

[1.8]
Исправлено: Экспорт проекта в файл *.dat (Res2DInv)

[1.7]
Добавлено: Импорт двумерных файлов *.m64Session (Скала 64 / Siber 64) на основе ERTLab
Добавлено: Новые примеры *.abmnui (общие)

[1.6]
Исправлено: Экспорт проекта в файл *.dat (Res2DInv)

[1.5]
Добавлено: Экспорт файлов *.m64Session (Скала 64 / Siber 64) на основе ERTLab в файл *.csv (Excel)

[1.4]
Добавлено: Загрузка файлов *.abmnui (общие)
Улучшено: Масштабирование графика кривых зондирования
Добавлено: Сохранение последней использованной маски файлов при загрузке данных

[1.3]
Удалено: Зависимость от распространяемого пакета Microsoft Visual C++

[1.2]
Добавлено: Загрузка отредактированных файлов *.d2d (Скала 48 / Siber 48)
Добавлено: Экспорт стандартного отклонения в файл *.data (ERTLab)

[1.1]
