Обзор раздела

ООО "Асу -Эксперт" является производителем:
  • скважинных геофизических приборов

  • наземной регистрирующей аппаратуры

Функции программного обеспечения

  • мониторинг в реальном времени и архивация данных ГИС, акустического каротажа и технологических параметров;
  • расчет геофизических параметров по заданным формулам;
  • калибровка каналов измерения и корректировка глубины по магнитным меткам;
  • просмотр и печать данных каротажных записей, таблиц параметров калибровки с параметрами графического вывода, взятыми из таблицы параметров регистрации;
  • инструментарий для оперативной оценки качества зарегистрированного каротажа, автоматическое и ручное редактирование без изменения исходного файла данных.
  • запись таблиц параметров скважинных приборов, макетов по видам исследований
