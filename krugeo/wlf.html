Комплекс программ WLF

Обработка и анализ данных электроразведки. Разработан в среде MATLAB, поставляется в виде загружаемых модулей и не требует предустановки MATLAB.

Комплекс предоставляет стандартный интерактивный графический интерфейс MATLAB. По желанию заказчика возможна поставка исходных текстов программ и описаний структуры данных для самостоятельного развития функциональных возможностей.

Возможности

Проектирование полевых работ
  • Привязка сканированных карт к системе координат пользователя.
  • Проектирование измерительных профилей и питающих источников.
  • Проектирование временной диаграммы источника тока.
  • Обработка цифровых каротажных диаграмм и построение геоэлектрических моделей.
Моделирование и инверсия

Горизонтально-слоистая модель среды с учётом поляризации.

  • Расчёт произвольных полей различных типов наземного источника во временной (ЗС) и частотной (ЧЗ) области.
  • Расчёт электрического поля вертикального (скважинного) источника в частотной области с учётом обсадной колонны.
  • Решение обратной задачи для методов ЧЗ и ЗС.
Обработка полевых данных AGE-xxl
  • Просмотр полевых записей и редакция служебных этикеток.
  • Обработка записей режимов ЧЗ и ЗС, формирование базы данных по площади.
  • Статистика полевых работ: оценки качества и производительности.
Геофизические трансформации и расчёт параметров
  • Поле эффективных сопротивлений Rω, Rt (нормировка на полупространство) для любой зоны источника.
  • St, Ht для ближней зоны (трансформация Тикшаева–Сидорова).
  • St, Ht для произвольной зоны (трансформация Грозы).
  • Интервальные сопротивления и построение слоистой модели среды.
  • Поляризационные параметры во временной и частотной области.
  • Дифференциальные параметры для скважинно-наземной электроразведки.
Анализ и визуализация данных
  • Преобразования полей во временной (частотной) и пространственной области.
  • Выделение регионального (фонового) и аномального поля.
  • Графики, карты, разрезы, поверхности, тела и сечения (2D и 3D).
  • Формирование отчётных изображений и экспорт результатов в различных форматах.
